CLI (hwid.cli)#

argparse command-line interface exposing version and info commands.

CLI application for the project.

A dependency-free argparse root for the hwid command. It exposes the same version / info commands as the Typer variant and hangs every enabled non-primary component off the root as a lazily-imported subcommand — hwid interactive (TUI), hwid web, … — rather than a separate hwid-<name> console script (see ADR-019 and ADR-020). Selected via cli_framework.
