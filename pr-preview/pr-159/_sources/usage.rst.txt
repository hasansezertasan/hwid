Usage
=====

As a library
------------

To use ``hwid`` in a project:

.. code-block:: python

   import hwid

   print(hwid.get_hwid())

As a CLI tool
-------------

Run it without installing, straight from PyPI:

.. code-block:: sh

   uvx hwid

Or, once installed, invoke the console script:

.. code-block:: sh

   hwid
